接入 API · 大约 3 分钟

还不会接 API？照这四步走一遍

你只需要一个 Key。它属于你自己的 DeepSeek 账号，费用也直接进你的账号， 不经过我；填进这里之后只存在你这台设备的浏览器里。整条链路是浏览器直连 DeepSeek，没有中间服务器。

  1. 1

    打开 DeepSeek 开放平台

    点这个链接：https://platform.deepseek.com/usage

    没有账号先注册一个（用手机号即可）；登录后看到的「用量信息」页面就是这里。余额不足也没关系，先拿到 Key，充值那一步随时能做。

  2. 2

    在左侧导航点「API keys」

    别在「用量信息」这里停住，看左边那一列，第二个就是 API keys。

  3. 3

    点右上角的「创建 API key」

    列表里可能已经有旧的 Key（比如你之前别的工具建的），不用管，直接新建一个给这里用。

  4. 4

    给 Key 起个名字，点「创建」

    名字随便写，比如「数学错题整理」，只是为了以后你自己分得清。点「创建」之后会弹出这个框：

    待会会出现 api 码，这个 出现一次后将无法查看， 请一定要保存到文档里，或者使用其它记载方式（密码管理器、手机备忘录都行）。

    关掉弹窗就再也看不到明文了，只能删掉重建——重建不额外收费，只是麻烦。

填好点「测试连接」，通了就进工作台。

顺手回答几个一定会问的问题

Key 填进去安全吗？
只存在你这台设备的浏览器里，不上传任何服务器，我这边看不到、也用不了。这也是这个工具说「数据不过手」的原因。
大概要充多少钱？
一次完整诊断约 2,400 tokens、约 0.02 元；100 道错题约 2 元。充 10 元能用很久。
提示 402 是什么意思？
账户余额不足。去平台左侧「充值」充一点，回到这里重试即可。
提示 401 呢？
Key 抄错、抄漏，或者已经被删除。重新复制一次，注意别把前后的空格带进去。
Key 找不到了怎么办？
只能重新创建一个。旧的那个可以在同一个页面删掉，避免以后混用。
